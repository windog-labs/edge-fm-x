# Retained Repository Evidence

These are small historical receipts used by the read-only task board. Their
content is copied byte for byte; the index records original relative paths,
repository paths, sizes, and SHA256 values. They are not new model runs and do
not assert that deleted model payloads or original machine paths still exist.

`retained-index-20261027.json` covers 45 receipts (about 0.6 MiB) and 13 existing
byte-exact figures in the paper handoff. Figure mappings require an exact path
identity and matching original/packaged hashes. Missing historical assets are
not replaced with plots from a different run or model.

The standalone paper delivery is in
`paper_handoff/edgefm_three_platform_20261026`. It has its own manifest and
standard-library verifier. Large models, engines, compiled caches, raw case
archives, temporary test output, and unrelated BEV source backups are excluded
from this repository delivery.
