## Diagnostic Timings

| Model | TTFT mean ms | Image Bytes to Tokens mean ms | Prepared-Tensor Generation mean ms | Decode tokens/s |
|---|---:|---:|---:|---:|
| 0.8B | 4459.187 | 4885.064 | 3589.850 | 35.222 |
| 2B | 7773.746 | 8137.747 | 6953.183 | 41.209 |

These are two measured calls per row, not stable performance estimates or a
model-size ranking. The input-to-token boundary includes in-memory JPEG decode,
processor/template/tokenization, H2D, vision, prefill, cached decode and CPU
token availability. It excludes initialization, image file IO, text detokenizing
and output validation/log IO. CPU token streaming is inside the measured path.
TTFT ends after the first token reaches CPU; decode throughput counts only the
remaining 15 tokens and includes generation finalization. No arbitrary timing
denominator clamp is used.

Separate CUDA-event hooks, absent from the timed loop, observed one vision call
and 16 model forward calls (prefill plus 15 decode calls). Vision time was
1986.615/5321.711 ms, and first-forward time including vision was
3147.040/6683.749 ms for 0.8B/2B. These diagnostics are not per-stage formal CDFs.
Pilot peak allocated bytes were 4339304960/7726970880; reserved bytes were
5496635392/9277800448. Peaks cover the reference-established warmup/measurement
phase and do not isolate steady state or cold initialization.

## Output and Ownership

All warmup and measured tokens, 4x16 INT64 values per model, equal that model's
untimed official-backend reference. Token-stream observations also match the
saved generated IDs. This establishes repeatability within the same backend,
not optimized-backend equivalence, float-logit losslessness or task accuracy.
The independent auditor rehashes complete input/output files, checks raw tokens,
recomputes timing arithmetic, and checks monitored process/GPU identities.
