# Qwen2.5-1.5B-Instruct Example

This directory provides a **Qwen2.5-1.5B-Instruct** example with the same structure as `qwen2.5-0.5b-instruct`, used for EdgeFM inference.

## Directory Structure

```
qwen2.5-1.5b-instruct/
├── README.md           # This document
├── download.sh         # Download the model from HuggingFace
├── engine_config.json  # Engine configuration (prefill_model_path points to the subdirectory)
├── generate.py         # Python inference example
└── qwen2.5-1.5b-instruct/   # Model files (generated by download.sh)
    ├── config.json
    ├── model.safetensors
    ├── tokenizer.json
    └── ...
```

## 1. Download the Model

```bash
cd examples/qwen2.5-1.5b-instruct
bash download.sh
```

The model will be downloaded to `qwen2.5-1.5b-instruct/` under the current directory (about 3GB).

## 2. Build EdgeFM

Run in the project root directory:

```bash
mkdir -p build && cd build
cmake .. -DPLATFORM=a800 -DCMAKE_CUDA_COMPILER=/usr/local/cuda-12.6/bin/nvcc
make -j && make install
```

## 3. Run the Example

Run in **this example directory** (to ensure that the relative path `qwen2.5-1.5b-instruct` in `engine_config.json` can be resolved correctly):

```bash
cd examples/qwen2.5-1.5b-instruct

# Set the runtime library paths as needed (consistent with test_all.sh)
export LD_PRELOAD=/usr/lib/x86_64-linux-gnu/libstdc++.so.6
export LD_LIBRARY_PATH=/path/to/edge-fm/build-a800/install/lib:/usr/local/cuda-12.6/lib64:$LD_LIBRARY_PATH

python3 generate.py
```

Replace `/path/to/edge-fm` with the actual path of the project root directory.

## Model and Configuration Notes

- **Qwen2.5-1.5B-Instruct**: `num_attention_heads=12`, `num_key_value_heads=2`, `group_size=6`.  
  EdgeFM has added support for `group_size=6` in FlashInfer, so this model can be used directly.
- In `engine_config.json`, `prefill_model_path` uses the relative path `qwen2.5-1.5b-instruct`, which is resolved relative to the directory where the configuration file is located, so it is recommended to run `generate.py` under `examples/qwen2.5-1.5b-instruct`.
