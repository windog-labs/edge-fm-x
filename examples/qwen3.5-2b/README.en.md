# Qwen3.5-2B Example

This directory is used to place and verify the `Qwen/Qwen3.5-2B` checkpoint.

## Directory Structure

```text
qwen3.5-2b/
├── README.md
├── download.sh
├── engine_config.json
├── generate.py
└── qwen3.5-2b/       # Model files directory, generated by download.sh
    ├── config.json
    ├── model.safetensors-00001-of-00001.safetensors
    ├── tokenizer.json
    └── ...
```

## 1. Download the Model

```bash
cd examples/qwen3.5-2b
bash download.sh
```

The model will be downloaded to `qwen3.5-2b/` under the current directory.

## 2. Transformers smoke test

```bash
cd examples/qwen3.5-2b
python3 generate.py
```

## EdgeFM Support Status

- `engine_config.json` reserves an EdgeFM configuration entry point, with `prefill_model_path` pointing to the local model directory.
- The Qwen loader currently supported by EdgeFM supports the `self_attn` weight layout of Qwen2.5/Qwen2.5-VL; the Qwen3.5 checkpoint uses the `model.language_model.layers.*.linear_attn.*` structure, so it cannot yet be run natively with EdgeFM `generate()` directly.
- To integrate with EdgeFM, a Qwen3.5 linear-attention model implementation and corresponding operator path need to be added in the future.
